## Funciones principales

**Easy URL Copy** hace que compartir y abrir URLs sea más limpio y rápido:

- **Copy Tab URL** — Un clic o atajo de teclado (`Ctrl+Shift+C` / `Cmd+Shift+C`) para copiar la dirección de la página actual
- **Open from Clipboard** — Atajo de teclado (`Ctrl+Shift+V` / `Cmd+Shift+V`) para abrir cualquier URL del portapapeles
- **Copy Clean Link** — Clic derecho en cualquier enlace para copiar una versión limpia sin visitarlo

## Modo URL limpia

Por defecto, Easy URL Copy elimina los parámetros de rastreo comunes de las URLs:

- Parámetros UTM (`utm_source`, `utm_medium`, etc.)
- IDs de rastreo de plataformas (`fbclid`, `gclid`, `msclkid`, etc.)
- Más de 70 parámetros de rastreo conocidos

Puedes desactivar cualquier parámetro integrado que necesites conservar, añadir parámetros personalizados que use tu sitio y alternar entre modo Completa y Limpia en cualquier momento en las opciones.

### Antes y después

```text
Antes: https://example.com/page?utm_source=email&fbclid=abc123&ref=tracking
Después: https://example.com/page
```

## ¿Por qué usar Easy URL Copy?

1. **Privacidad** — Deja de compartir parámetros de rastreo al copiar enlaces. Mantén privados tus hábitos de navegación.
2. **Velocidad** — Una pulsación de tecla en lugar de editar URLs manualmente o usar herramientas de terceros.
3. **Flexibilidad** — Desactiva o añade parámetros de rastreo según tu flujo de trabajo.
4. **Sin sobrecarga** — Extensión ligera (~0.3 MB). Funciona silenciosamente en segundo plano.
5. **Gratis y abierta** — Sin funciones premium, sin anuncios, sin rastreo.

## Atajos de teclado

| Acción | Windows / Linux | Mac |
| --- | --- | --- |
| Copiar URL de la pestaña | `Ctrl+Shift+C` | `Cmd+Shift+C` |
| Abrir del portapapeles | `Ctrl+Shift+V` | `Cmd+Shift+V` |

Visita `chrome://extensions/shortcuts` para reasignar cualquier atajo según tu preferencia.

## Cómo funciona

1. **Instala** la extensión — añade un icono a tu barra de herramientas
2. **Abre las opciones** (clic derecho en la extensión → Options) y elige el formato de URL
3. **Copia URLs** con el atajo de teclado o el botón de la barra de herramientas
4. **Gestiona las reglas de rastreo** en las opciones si necesitas personalizar el comportamiento

Toda la configuración se sincroniza entre tus dispositivos Chrome.

<Admonition type="info">

**Privacidad primero.** Easy URL Copy funciona completamente en tu dispositivo — no se envían datos a servidores, no requiere cuentas y la configuración se guarda localmente en tu navegador. Completamente sin conexión excepto al leer el portapapeles y la pestaña actual.

</Admonition>

## Permisos explicados

Easy URL Copy requiere estos permisos — ninguno se usa para rastrearte:

| Permiso | Motivo |
| --- | --- |
| `tabs` | Leer la URL de la página actual para copiarla |
| `clipboardRead` / `clipboardWrite` | Copiar URLs al portapapeles y leer URLs del portapapeles |
| `storage` | Guardar tus preferencias (formato de URL, parámetros de rastreo personalizados) |
| `scripting` | Inyectar acceso al portapapeles en páginas web (limitación de Chrome MV3) |
| `contextMenus` | Añadir "Copy clean link" al hacer clic derecho en un enlace |
