## Core features

**Easy URL Copy** makes sharing and opening URLs cleaner and faster:

- **Copy Tab URL** — One click or keyboard shortcut (`Ctrl+Shift+C` / `Cmd+Shift+C`) to copy the current page's address
- **Open from Clipboard** — Keyboard shortcut (`Ctrl+Shift+V` / `Cmd+Shift+V`) to open any URL from your clipboard
- **Copy Clean Link** — Right-click any link to copy a cleaned version without visiting it

## Clean URL mode

By default, Easy URL Copy removes common tracking parameters from URLs:

- UTM parameters (`utm_source`, `utm_medium`, etc.)
- Platform tracking IDs (`fbclid`, `gclid`, `msclkid`, etc.)
- 70+ other known tracking parameters

You can disable any built-in parameter you need to keep, add custom parameters your site uses, and toggle between Full and Clean mode anytime in options.

### Before and after

```text
Before: https://example.com/page?utm_source=email&fbclid=abc123&ref=tracking
After:  https://example.com/page
```

## Why use Easy URL Copy?

1. **Privacy** — Stop sharing tracking parameters when you copy links. Keep your browsing habits private.
2. **Speed** — One keystroke instead of manually editing URLs or using third-party tools.
3. **Flexibility** — Disable or add tracking parameters to match your workflow.
4. **No bloat** — Lightweight extension (~0.3 MB). Runs silently in the background.
5. **Free & open** — No premium features, no ads, no tracking.

## Keyboard shortcuts

| Action | Windows / Linux | Mac |
| --- | --- | --- |
| Copy tab URL | `Ctrl+Shift+C` | `Cmd+Shift+C` |
| Open from clipboard | `Ctrl+Shift+V` | `Cmd+Shift+V` |

Visit `chrome://extensions/shortcuts` to rebind any shortcut to your preference.

## How it works

1. **Install** the extension — it adds an icon to your toolbar
2. **Open options** (right-click extension → Options) and choose URL format
3. **Copy URLs** with the keyboard shortcut or toolbar button
4. **Manage tracking rules** in options if you need to customize behavior

All settings sync across your Chrome devices.

<Admonition type="info">

**Privacy first.** Easy URL Copy runs entirely on your device — no data sent to servers, no accounts required, and settings stored locally in your browser. Completely offline except when reading your clipboard and current tab.

</Admonition>

## Permissions explained

Easy URL Copy requires these permissions — none are used to track you:

| Permission | Why |
| --- | --- |
| `tabs` | Read the current page URL to copy it |
| `clipboardRead` / `clipboardWrite` | Copy URLs to clipboard and read URLs from clipboard |
| `storage` | Save your preferences (URL format, custom tracking parameters) |
| `scripting` | Inject clipboard access into web pages (Chrome MV3 limitation) |
| `contextMenus` | Add "Copy clean link" when you right-click a link |
